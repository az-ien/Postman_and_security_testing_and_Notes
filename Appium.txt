Appium: 
Appium is used to automate mobile testing. It can be integrated with selenium webdriver. 

Why appium: 
It is an open source . 
It supports selenium as a native configurations 
it can be used on multiple browsers . 
It supports android/IOS apps as well as native and hybrid apps

Advantages:

1. It can support multiple languages (Java,python, .net)
2. It supports both ios and androird apk
3. Multiple browsers. 
4. Multiple lanuguages
5. Open source
6. Not depenedetn on mobile device 
7. Does not require modification on apps 

Limitation:

1. Cannot test below 4.2 android
2. Little support for hybrid apps 
3. Cannot run appium inspector on windows
